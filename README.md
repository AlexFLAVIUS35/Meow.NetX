## -- Upcoming Features

- Being able to switch from steam_appid 480 and the original Rec Room steam_appid.
  
- Multiple Installations
  
- Uses Windows File Explorer To Search For Meow.Net Folder Faster.

## -- Installation

-- **From source**

Requirements:
- .NET 10 SDK
- Git

Clone the repository:

```bash
git clone https://github.com/AlexFLAVIUS35/Meow.NetX.git
cd Meow.NetX
dotnet build
```



-- **From releases**

NO RELEASE INSTALLATION IS AVAILABLE YET.
